## 🚀 Tutorial de instalação do projeto


## 📥 1. Clonar o repositório

```bash
git clone https://github.com/Renn4nn/carona-universitaria-backend.git
cd carona-universitaria-backend
```

---

## 📦 2. Instalar dependências

```bash
npm install
```

---

## ▶️ 3. Iniciar o servidor

```bash
npm start
```
